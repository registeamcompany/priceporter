# 🤖 AI Development Guide for Price Reporter Landing Page

Цей файл створено спеціально для AI-агентів. Проєкт реалізовано на **модульній системі Vite + Vanilla JS/CSS** для максимальної економії токенів, швидкості збірки та відсутності помилок при зміні коду.

---

## 🏗 Архітектура та Точки Входу

- `/index.html` — **Єдиний головний лендінг**. Містить каркасні контейнери `<div id="***">`.
- `/src/main.js` — **Головне ядро проєкту**. Завантажує HTML-компоненти через `?raw` імпорти, монтує їх у каркас, підключає стилі та скрипти.
- `/src/components/` — Ізольовані HTML-файли розмітки (один файл = один блок).
- `/src/styles/` — Ізольовані CSS-файли блоків + `global.css` та токени дизайн-системи.
- `/src/scripts/` — Логіка форм, квіза, анімацій (`animations.js`), акордеонів (`faq.js`) та липкої шапки (`sticky-ui.js`).

---

## ⚡️ Суворі Правила Роботи для AI-Агентів

1. **Економія токенів**: Якщо користувач просить змінити блок X — відкривайте ТІЛЬКИ `src/components/...` та відповідний `src/styles/...`. Не читайте весь проєкт або нерелевантні файли.
2. **Ніяких inline JS чи Inline стилів**: Весь JavaScript розміщується у `/src/scripts/`, увесь CSS — у відповідних `.css` файлах.
3. **Використання токенів кольорів**: Кольори беруться виключно з токенів (`var(--blue-900)`, `var(--brand-accent)` `#FF6000`, `var(--green-700)`). Жодних довільних hex-кодів.
4. **Принцип 100% збереження копідеку**: Не змінюйте та не переписуйте текстівок клієнта без прямої вказівки замовника.

## 🎯 Перевірка Збірки Перед Завершенням

Після внесення будь-яких змін обов'язково виконайте перевірку збірки:

```bash
npm run build
```

Збірка має завершуватися успішно без помилок у консолі (0 errors).

---

## 📋 Поточний Стек Та Компоненти

- **Core**: HTML5, Vanilla JavaScript (ES Modules).
- **Styles**: Vanilla CSS3 з CSS-змінними (Tokens).
- **Bundler**: Vite 5+.
- **Main Entry**: `/index.html` -> `/src/main.js`.
