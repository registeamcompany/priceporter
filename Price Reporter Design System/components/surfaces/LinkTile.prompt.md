The hero's blue square navigation tiles. Three columns, each one blue depth: a `head` tile with the speech-bubble tail, then a 2-wide grid of link tiles beneath it.

```jsx
<LinkTile head video depth={1} label="Get GSA Contract" />
<LinkTile depth={1} label="What is GSA Contract" />
<LinkTile depth={1} icon="settings" label="Do You Qualify?" />
```

Hover fills the tile orange. Never round the corners, never add a shadow.
