Labelled text field used across contact forms, catalog search and app filters.

```jsx
<Input label="Work email" type="email" required placeholder="you@company.com" icon="mail" />
<Input label="GSA contract number" hint="Format: 47QSWA18D008F" />
<Input label="Message" multiline rows={4} />
```

Pass `error` to switch the hint line to the red error state.
